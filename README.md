# おぶこわ - Context Workspace for Obsidian

**Obsidianを母艦として、プロジェクトごとにワークスペースを構成できるMarkdownエディタ**

膨大なVault（フォルダ）の中から、**「今必要なファイル」だけを集めて表示し、目の前の作業に集中する**ことを目指して開発したローカル専用デスクトップアプリです。（Obsidianと併用せず、単独のMarkdownエディタとしてもお使いいただけます）

※現在開発中のバージョンです。
Obsidian記法とダッシュボードの機能は実装中です。
メインの機能は問題なく動作しますが、一部未完成な部分があります。ご了承ください。

##  コンセプトと特徴

Obsidianを使っていて「プロジェクトごとにタグを分けるのが面倒」「ファイルが増えすぎてツリーがごちゃごちゃする」と感じたことはありませんか？
「おぶこわ」を使えば、Obsidian側のフォルダ構造やタグを汚すことなく、アプリ内だけでプロジェクトごとの「ワークスペース」を構築し、必要な情報だけにアクセスできます。

**Obsidianとの違い**

Obsidianは、一つのフォルダの下をVaultとして管理します。
おぶこわは、複数のフォルダを集めて一つのワークスペースとして管理します。

**使用例**
  
* **複数Vault・フォルダにまたがる資料を一つのワークスペースで管理**
  異なるVaultに保存された日記・資料・メモなどから、プロジェクトごとに必要なファイルだけを切り出し、一つのワークスペースで管理。

* **大きなVaultから、今必要な情報だけを取り出して作業**
  膨大なファイルを抱えたVault全体を探し回るのではなく、スマートフォルダや検索で必要なファイルだけを集め、プロジェクトに必要な情報に集中

* **Git管理下のドキュメントと、Vault内のマニュアルなどを一緒のワークスペースで管理**

###  主な機能

#### プロジェクトごとのワークスペース
Obsidian Vaultの中から必要なファイルだけを集め、
プロジェクトごとに独立した作業環境を構成できます。

Vaultのファイルを移動・コピーする必要はありません。
同じファイルを複数のワークスペースから参照することもできます。

#### スマートフォルダ
条件に応じてファイルを自動収集するフォルダを作成できます。

対象:
- 指定したフォルダ
- ワークスペース全体

条件:
- 特定のタグを含む / 含まない
- 作成日・更新日が新しいファイル〇件
- 複数条件の組み合わせ

Obsidian側でプロジェクトごとにタグを細かく管理しなくても、
おぶこわ側で作業コンテキストを分けて管理できます。

#### ダッシュボード
ワークスペースの作業状況を一つの画面にまとめて表示できます。

- 未完了タスク
- 検索結果

などをウィジェットとして配置できます。

また、mdファイルとして自由に編集可能です。

#### ワークスペース内検索
現在のワークスペースに登録されているファイルだけを対象に、
ファイル名や本文を検索できます。

#### ToDo一覧
ワークスペース内のMarkdownから未完了タスクを集めて一覧表示できます。

ファイル単位、または見出し階層を再現した形で整理して表示できます。
一覧からチェックを変更すると、元のMarkdownファイルにも反映されます。

### Obsidian互換Markdown
Markdownの基本的な記法に加えて、

- Wikiリンク
- Callout（`>[!info]` など）
- タグ
- フロントマター

など、Obsidianで使われる記法を利用できます。

### その他

- ワンクリック・タグ操作
- ピン留め
- よく使うリンクの登録
- フォント・文字サイズ・見出しサイズの変更
- ダーク / ライト / 羊皮紙 / カスタムテーマ

##  ダウンロードとインストール

1. 本リポジトリの [Releases](../../releases) ページにアクセスします。
2. 最新バージョンのインストーラーをダウンロードしてください。
3. ダウンロードしたファイルを実行してインストールします。

### 【重要】初回起動時の警告について

初回起動時にOSのセキュリティ機能によって以下の警告が表示される場合がありますが、これは署名を取得していないためであり、ウイルス等は含まれておりません。

  * 「WindowsによってPCが保護されました」という青い画面が出た場合、「詳細情報」をクリックし、「実行」ボタンを押してください。

## データとプライバシーについて

* **完全ローカル動作**: 本アプリはインターネットを経由してファイルを外部に送信することは一切ありません。
* **保存先**:
  * マークダウンファイルは、あなたが指定したPC内のフォルダ（ObsidianのVaultなど）のものを直接読み書きします。
  * ワークスペースの構成情報、登録したリンクやタグ、設定データなどのメタ情報は、OS標準のアプリデータ保存領域（`AppData`など）にローカル保存されます。
